# ⚽ Sistema de Predicción de Partidos de Fútbol con IA

Este proyecto utiliza Inteligencia Artificial para analizar el nivel y rendimiento reciente de los equipos de fútbol y predecir los resultados de los partidos.

## 🚀 Características
- **Datos dinámicos:** Conexión directa con la API de Kaggle para actualizaciones diarias.
- **Modelo Predictivo:** Algoritmo Random Forest entrenado con más de 55,000 partidos.
- **Interfaz Gráfica:** Desplegado de forma interactiva en la nube usando Streamlit.

## 🛠️ Instalación Local
1. Clona este repositorio.
2. Instala las dependencias: `pip install -r requirements.txt`
3. Ejecuta la app: `streamlit run app.py`
